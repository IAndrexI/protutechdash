In-App Switcher Integration Active

This page simulates an existing Protutech application (like Homebox, DiscoPanel, or Vaultwarden) that has the Protutech Launcher embed script installed.

Notice the floating 9-dot launcher button in the top-right corner. Clicking it gives the user instantaneous access to all their other Protutech apps without needing to leave the current application!

How to add this to any of your apps:

Simply paste this single line before </body> in any web app:

<script src="https://iandrexi.github.io/protutechdash/embed/protutech-launcher.js" data-position="top-right"></script>
