Embed Launcher in Your Other Apps

Add a unified Protutech App Switcher button to any of your other web applications. When clicked, it opens a clean slide-out menu allowing you to jump instantly between all your apps without leaving!

Option 1: Single HTML Script Tag (Vanilla / PHP / Any Web App)

<script src="https://iandrexi.github.io/protutechdash/embed/protutech-launcher.js" data-position="top-right"></script>

Option 2: React / Next.js Component

import { useEffect } from 'react';

export default function ProtutechSwitcher() {
  useEffect(() => {
    const s = document.createElement('script');
    s.src = 'https://iandrexi.github.io/protutechdash/embed/protutech-launcher.js';
    s.setAttribute('data-position', 'top-right');
    document.body.appendChild(s);
    return () => s.remove();
  }, []);
  return null;
}

Option 3: Embedded Iframe / Sidebar Widget

<iframe src="https://iandrexi.github.io/protutechdash/" style="width: 100%; height: 600px; border: none; border-radius: 12px;"></iframe>
